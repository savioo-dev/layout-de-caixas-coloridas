# Layout de caixas coloridas

Este projeto é um layout de caixas coloridas desenvolvido como parte da certificação de Web Design Responsivo do freeCodeCamp.
💻 Tecnologias utilizadas

- HTML5: Estruturação semântica do cabeçalho, contêiner flexível e das caixas de conteúdo.
- CSS3: Estilização visual e aplicação de conceitos modernos de layout.

🚀 Conceitos de CSS Flexbox aplicados

- `display: flex`: Transformou o contêiner em um ambiente flexível.
- `flex-wrap: wrap`: Permitir a quebra automática de linha para maior responsividade.
- `order`: Reorganização da ordem visual dos elementos filhos.
- `flex-grow`: Distribuição dinâmica do espaço excedente entre os itens.
